# Dataset / Veri Seti

## 🇹🇷 Türkçe

Bu klasörde kullanılan veri dosyaları GitHub'a eklenmemiştir.

Bu proje, daha önce hazırlanan **network-intrusion-detection-ml** projesinde oluşturulan ön işlenmiş (preprocessed) eğitim ve test veri dosyalarını kullanmaktadır.

Bu projeyi çalıştırmak isteyen kullanıcıların öncelikle aşağıdaki projeyi indirerek gerekli veri dosyalarını oluşturması veya kullanması gerekmektedir.

Beklenen dosyalar:

- X_train.csv
- X_test.csv
- y_train.csv
- y_test.csv

Notebook'lar GitHub'a çalıştırılmış (executed) şekilde yüklendiği için sonuçlar görüntülenebilir. Ancak hücreleri yeniden çalıştırmak isteyen kullanıcıların veri dosyalarını bu klasöre eklemesi gerekmektedir.

## 🇬🇧 English

The dataset files are not included in this repository.

This project uses the preprocessed training and testing datasets generated in the **network-intrusion-detection-ml** project.

To reproduce the experiments, users should first download or generate the processed dataset from that repository and place the following files into this directory:

- X_train.csv
- X_test.csv
- y_train.csv
- y_test.csv

The notebooks in this repository are uploaded with all cells already executed, allowing users to inspect the outputs directly. However, to rerun the notebooks, the processed dataset files must be placed in this folder.
